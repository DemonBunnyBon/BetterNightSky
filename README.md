# Better Night Sky

This is a mod for The Long Dark that replaces the Moon and Stars with a more detailed representation.

![NightSky](https://raw.githubusercontent.com/DemonBunnyBon/BetterNightSky/refs/heads/main/Images/night-sky.jpg)

Features: 
- The mod completely overhauls the night sky sphere with new textures giving the moon, stars and the abyss itself a new look.
- The look of the moon changes over time with moon phases.
- Adds the possibility of *meteor showers* appearing in the sky, now with full customization options!

## Installation

- Install [Mod Settings](https://github.com/DigitalzombieTLD/ModSettings/releases/), it is required.
- Download the latest version of Better Night Sky from the [releases page](https://github.com/DemonBunnyBon/BetterNightSky/releases).
- Move Better-Night-Sky.dll in your mods folder.
